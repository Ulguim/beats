## Observações
- A integração GitHub permite arquivos UTF-8 via commit; binários grandes ainda dependem de upload separado. Guardar o ZIP de transferência de contexto entregue ao usuário.
- Não foi possível exportar cada chat do projeto palavra por palavra. Este pacote preserva documentos e histórico consolidado.
- Direitos de trilha, imagem, foto, catálogo, nome, marca e tipografia precisam ser checados antes de uso comercial.
